# EXIF 보기와 개인 정보 지우기

날짜: 2026-11-16. 승인: 사용자 ("그대로 진행").

## 왜

사진을 남에게 보내기 전에 개인 정보(특히 촬영 위치 GPS)가 들어 있는지 보고, 지울 수 있어야 한다. 지금 미리보기 칸에는 이름, 크기, 용량, 수정 시각만 나온다.

## 목표

- 미리보기 칸에 촬영 정보(카메라, 찍은 때, 노출, 위치)를 보인다. 위치가 있으면 붉은 글씨로 눈에 띄게 한다.
- 고른 파일들의 개인 정보 메타데이터를 한 번에 지운다.

## 하지 않는 것

- EXIF 고치기(값 바꾸기), GPS만 골라 지우기.
- HEIC, RAW, GIF, TIFF 지우기. 압축 파일 안 그림 지우기 (읽기만 된다).
- 사본 저장. 원래 파일에 덮어쓴다 (회전과 같다).

## 실패로 보는 것

- 지운 뒤 화질이 떨어지거나 색이 바뀌는 것 (다시 압축하거나 ICC를 버리는 것).
- 지운 뒤 세로 사진이 옆으로 눕는 것 (방향 값을 잃는 것).
- 쓰다가 실패해서 파일이 깨지는 것.

## 방법

| 안 | 장단점 | 결정 |
|---|---|---|
| 1. 메타데이터 덩어리만 떼어 내기 | 그림 데이터를 건드리지 않아 화질 그대로. 새 크레이트 없음. 회전(src/rotate.rs)과 같은 방식 | 고름 |
| 2. 그림을 디코딩해서 다시 저장 | JPEG 화질 저하, ICC 손실 | 버림 |
| 3. exiftool 같은 바깥 프로그램 | exe 하나로 끝나지 않음 | 버림 |

## 설계

- 지우는 것
  - JPEG: APP1 Exif, APP1 XMP(표준과 확장), APP13(Photoshop/IPTC), COM.
  - PNG: eXIf, tEXt, iTXt, zTXt.
  - WebP: EXIF, XMP 덩어리. VP8X 플래그도 맞춘다.
- 남기는 것: 그림 데이터, ICC 색 정보(JPEG APP2, PNG iCCP, WebP ICCP), JFIF/Adobe 마커.
- 방향 값이 1이 아니면 방향 태그 하나만 든 작은 EXIF를 다시 넣는다.
- 쓰기는 회전과 같은 `write_atomic` (옆에 임시 파일을 쓰고 이름을 바꾼다).
- 미리보기 칸에 보이는 것: 카메라(제조사, 모델), 렌즈, 찍은 때, f값, 셔터 속도, ISO, 초점 거리, 위치(십진 위도·경도, 붉은 글씨).
  - "자세히"를 누르면 모든 태그를 보인다.
  - EXIF가 없으면 "촬영 정보 없음"이라고 쓴다.
  - 포커스가 바뀔 때 한 번만 읽고 캐시한다.
- 지우기 단추는 둘이다.
  - 미리보기 칸의 단추.
  - 목록과 크게보기의 오른쪽 버튼 메뉴 항목 "개인 정보 지우기". 여러 장을 골랐으면 모두 지운다.
- 지우기 전에 확인 창을 띄운다: "N개 파일의 촬영 정보와 위치를 지웁니다. 되돌릴 수 없습니다."
  - 지울 수 없는 형식만 골랐으면 메뉴 항목을 끈다.
  - 끝나면 실패한 파일 수와 까닭을 알린다.

## 만드는 사람에게 맡긴 것

확인 창과 알림의 모양(지금 있는 대화상자와 같게), 태그 이름의 한국어 표기.
